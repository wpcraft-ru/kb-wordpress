## Когда выбирать этот тип

Нужен для точечной кампании: один оффер, одна аудитория, одно целевое действие. Хорошо подходит для запусков, вебинаров, акций, лид-магнитов и проверки спроса.

## Ключевые особенности

- Фокус на одной конверсии: заявка, покупка, регистрация, контакт.
- Воронка на странице: оффер, доказательства, FAQ, CTA.
- Критичны скорость, мобильный UX и корректная аналитика рекламы.
- Часто короткий жизненный цикл: запуск, тест, итерации, архив.

## Оптимальный стек

- **AstroJS** - при максимальном упоре на скорость и SEO/SEM-эффективность.
- **WordPress + Blocks** - когда маркетингу важно часто менять блоки без разработчика.

## Бриф-шаблон

1. Целевое действие: что должен сделать посетитель?
2. Оффер и УТП: какую боль закрывает предложение?
3. Блоки страницы: какие секции обязательны для решения?
4. Источник трафика: какие каналы приводят посетителей?
5. Обработка лида: куда уходит заявка и кто отвечает?
6. Аналитика: цели, пиксели, UTM, события, A/B-гипотезы.
7. Ограничения: сроки, бюджет, референсы, юридические требования.
