## Как использовать классификацию

1. Сначала определите, какой из 7 типов ближе всего к задаче.
2. Затем проверьте, достаточно ли одного сайта или нужен гибрид, например корпоративный сайт с блогом или магазин с B2B-кабинетом.
3. После этого выберите стек по сложности данных, частоте обновления и требованиям к редактуре.
4. И только потом собирайте детальный бриф и смету.
