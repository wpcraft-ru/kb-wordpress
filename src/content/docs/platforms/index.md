## Что в этом разделе

Здесь собраны платформы, с которыми мы чаще всего работаем при создании сайтов и веб-продуктов. Раздел помогает быстро понять, чем отличается CMS, backend-framework, frontend-framework и архитектурный подход, и выбрать стек под задачу.

## Быстрый обзор

| Платформа | Роль | Когда выбирать |
|---|---|---|
| WordPress | CMS | Блоги, корпоративные сайты, контентные проекты, сайты с частыми правками |
| WooCommerce | E-commerce plugin/platform | Интернет-магазины на базе WordPress: каталог, оплата, доставка, налоги |
| Laravel | Backend framework | Кастомная логика, B2B-кабинеты, CRM, интеграции, сложные процессы |
| Jamstack | Архитектура | Высокая производительность, статическая генерация, API-first |
| Next.js | React framework | Headless CMS, интерактивные интерфейсы, SSR/SSG/ISR, full-stack React |
| Astro | Frontend framework | Контентные сайты, лендинги, маркетинговые страницы, минимум JS |

## Как читать этот раздел

1. Сначала определите роль платформы в проекте.
2. Затем посмотрите, какие сценарии она закрывает лучше всего.
3. После этого сравните ограничения и типичные компромиссы.
4. Если нужен не типовой сайт, а продукт, см. [Кастомный сайт или веб-приложение](../create-websites/custom-solutions.md).
