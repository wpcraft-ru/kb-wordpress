## Что такое Next.js

Next.js — React-фреймворк для full-stack веб-приложений. Он подходит там, где нужен современный frontend, интеграция с API и несколько режимов рендеринга.

## Когда Next.js подходит лучше всего

- headless CMS-сайты;
- интерактивные маркетинговые и продуктовые интерфейсы;
- проекты с SSG, SSR, ISR или гибридным рендерингом;
- приложения, где React уже является стандартом команды;
- интерфейсы, которые должны быстро масштабироваться.

## Сильные стороны

- App Router и современная архитектура;
- серверные и клиентские компоненты;
- гибкие режимы рендеринга;
- богатая экосистема и стандарт де-факто для React-web;
- удобен для интеграции с CMS и backend API.

## Когда Next.js особенно уместен

- если нужен headless-фронтенд к WordPress или другому CMS;
- если хочется совместить SEO и интерактивность;
- если проекту важны производительность и гибкая схема доставки контента.
