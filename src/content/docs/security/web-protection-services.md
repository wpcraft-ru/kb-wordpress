Рынок защиты сайтов и CDN в России за последние два года прошёл через серьёзную перестройку. После ухода Cloudflare из РФ (июнь 2025 — массовая фильтрация IP-адресов российскими провайдерами) и роста требований к локализации (152-ФЗ, КИИ, реестр отечественного ПО) на первый план вышли российские вендоры. Параллельно выросли и атаки: DDoS-мощности в Рунете регулярно превышают 1 Тбит/с, а L7-атаки на веб-приложения и API стали нормой, а не исключением.

В этом обзоре — десять сервисов, которые покрывают весь спектр задач: от бесплатного CDN для небольшого сайта до enterprise-WAF для КИИ-объекта. Для каждого — тип решения, плюсы, минусы, тарифы и сценарий «когда выбирать».

## Составляющие

Ниже — детальный разбор каждого сервиса: тип решения, сильные и слабые стороны, тарифная сетка и сценарий выбора.

### Cloudflare

**Тип:** Глобальная CDN + DDoS-защита (L3–L7) + WAF + Workers.

**Плюсы:**
- Базовый функционал (CDN, DNS, SSL, DDoS-защита) доступен на бесплатном тарифе
- Глобальная распределённая сеть с высокой производительностью
- Широкая экосистема: Workers, R2, D1, Stream, Zero Trust
- Мощный WAF, антибот, Page Rules, аналитика

**Минусы:**
- **Критично для РФ:** с июня 2025 года провайдеры массово фильтруют IP-адреса Cloudflare. Пользователи из России видят только первые ~16 КБ данных — сайты не загружаются
- Нет российского юридического лица, не в реестре ПО РФ
- Оплата из РФ затруднена
- План per-zone: каждый домен на Pro/Business — отдельная абонплата

**Тарифы:** Free ($0), Pro ($20–25/мес), Business ($200–250/мес), Enterprise (индивидуально).

**Когда выбирать:** Только для проектов с преимущественно зарубежной аудиторией. Для российского трафика — категорически не рекомендуется.

### Yandex Smart Web Security

**Тип:** WAAP (L7 Anti-DDoS + WAF + антибот + rate limiting) + Yandex DDoS Protection (L3/L4) + Yandex CDN.

**Плюсы:**
- Комплексный WAAP-подход: L7 Anti-DDoS, WAF (OWASP Top 10 + ML-WAF), антибот, Advanced Rate Limiter
- ML и поведенческий анализ (Smart Protection) на основе опыта Яндекса
- Интеграция со SmartCaptcha
- Интеграция с Yandex Cloud CDN — полноценная альтернатива Cloudflare
- Юридическая локализация для РФ, инфраструктура в России
- Подходит как для ресурсов в Yandex Cloud, так и для внешних origin-серверов

**Минусы:**
- Относительно молодой сервис (анонс L7-части в 2024)
- Фокус на Рунет — для глобальных проектов менее оптимален
- Для full-stack защиты L3/L4 требуется дополнительно подключать Yandex DDoS Protection (Curator)
- Требуется компетенция для тонкой настройки WAF

**Тарифы:** Уточняются индивидуально. На этапе Public Preview предоставлялся ограниченному кругу по запросу.

**Когда выбирать:** Если вы уже в Yandex Cloud и хотите «всё из одной консоли» — оптимальный выбор. Лучшая российская альтернатива Cloudflare.

### DDoS-Guard

**Тип:** Российский сервис DDoS-защиты (L3–L7) + CDN + WAF + защищённый DNS.

**Плюсы:**
- Эффективная фильтрация L3–L7 (SYN/UDP/HTTP-флуд)
- Фиксированная цена без доплат за отражённые атаки
- Встроенный CDN
- Есть бесплатный тариф (с ограничениями) и бесплатный тестовый период 2–3 дня
- Геоблокировка, бесплатный SSL

**Минусы:**
- Цены выше среднего: Basic от 8000 ₽/мес
- Бесплатный тариф сильно ограничен: общий IP, заглушка для всех пользователей, лимит 50 Мбит/с
- Поддержка на бесплатном тарифе отсутствует

**Тарифы:** Basic (8000 ₽/мес), Normal (20 000 ₽/мес), Medium (48 000 ₽/мес, 3 домена), Premium (80 000 ₽/мес, 5 доменов), Enterprise (200 000 ₽/мес). Есть бесплатный тариф.

**Когда выбирать:** Для быстрой защиты проекта с минимальным бюджетом — есть бесплатный тариф и тестовый период.

### StormWall

**Тип:** Российский сервис DDoS-защиты + CDN + WAF.

**Плюсы:**
- Мощная многоуровневая фильтрация Triple Filter (L3–L7)
- BanHammer для HTTP-флуда
- Сеть фильтрации >8 Тбит/с
- Поддержка нестандартных протоколов и игровых серверов (GRE-туннель)
- Есть отдельный продукт StormWall Gaming
- Бесплатный тестовый период

**Минусы:**
- Цены заметно выросли к 2026 (старт ~10 000–11 000 ₽/мес для сайтов)
- Стоимость дополнительных опций (WAF, защита API) может значительно увеличить итоговую цену
- Часть функционала доступна только на старших тарифах

**Тарифы:** От ~10 000–30 000 ₽/мес для сайтов. Network-тарифы для провайдеров индивидуально.

**Когда выбирать:** Для проектов, которым нужна мощная защита от DDoS с возможностью тонкой настройки фильтрации.

### NGENIX

**Тип:** Российская платформа CDN + DDoS-защита (L3–L7) + WAF + антибот + DNS.

**Плюсы:**
- Комплексная платформа «всё-в-одном»: CDN, DDoS, WAF, DNS, SSL/TLS, мониторинг
- Сеть из 50+ узлов в РФ и СНГ, пропускная способность >7 Тбит/с
- Интеграция с Arbor PeakFlow на сети Ростелекома
- Поддержка ГОСТ-криптографии (RSA, ECDSA, ГОСТ 34.10)
- Включён в реестр российского ПО (№ 20947)
- Метрики в формате Prometheus для DevOps

**Минусы:**
- Нет бесплатного тарифа, минимальный — 6900 ₽/мес
- Географический фокус — РФ и СНГ (не подходит для глобальных проектов)
- Функционал сфокусирован на веб-ресурсах

**Тарифы:** Promo (6900 ₽/мес), Lite (13 900 ₽/мес), Start (от 23 900 ₽/мес), Pro (от 59 900 ₽/мес), Ultimate (индивидуально).

**Когда выбирать:** Для высоконагруженных российских проектов с упором на скорость и производительность CDN.

### Selectel

**Тип:** Российский IaaS-провайдер с DDoS-защитой (L3/L4 — встроенная, L7 — через партнёров) + CDN + WAF.

**Плюсы:**
- Базовая L3/L4-защита включена во все продукты бесплатно
- Возможность подключать партнёрские решения (DDoS-Guard, Curator, StormWall) через единую панель
- Есть собственный управляемый WAF (Elementary — 36 600 ₽/мес, Advisory — 92 720 ₽/мес)
- Отдельный CDN от 500 ₽/мес
- Подробная статистика по атакам

**Минусы:**
- L7-защита — только через партнёров (дополнительная плата)
- Собственный WAF дорогой для небольших проектов
- Базовая защита фильтрует только входящий трафик

**Тарифы:** Базовая защита — бесплатно с инфраструктурными услугами. Партнёрские решения — по тарифам DDoS-Guard/Curator. CDN — от 500 ₽/мес. WAF — от 36 600 ₽/мес.

**Когда выбирать:** Если уже пользуетесь инфраструктурой Selectel и хотите подключить защиту в одном месте.

### Cloud4Y

**Тип:** Российский IaaS-провайдер с DDoS-защитой + WAF + комплексной защитой ИТ-инфраструктуры.

**Плюсы:**
- Комплексный стек безопасности: DDoS, WAF, IAM, PCI DSS
- Геораспределённая сеть фильтрации, прямые подключения к Tier-1 операторам
- Интеграция со StormWall и сертифицированной платформой WAF
- Соответствие ФСТЭК и PCI DSS
- Дата-центры уровня TIER III
- VMware-платформа, SLA 99,982%

**Минусы:**
- DDoS-защита — платная опция (подключается отдельно)
- Ориентация на корпоративный сегмент — порог входа выше
- Не все функции доступны малым проектам

**Тарифы:** Индивидуально, под запрос. Фиксированные тарифы на облачные сервисы без привязки к объёму трафика.

**Когда выбирать:** Для корпоративных клиентов с требованиями к соответствию регуляторам и комплексной защите.

### Qrator Labs

**Тип:** Специализированный российский сервис DDoS-защиты (L3–L7) + WAF + антибот + CDN + защищённый DNS.

**Плюсы:**
- Мощная фильтрующая сеть (3+ Тбит/с, Anycast)
- Защита L3–L7 в одном решении
- Встроенные WAF и Bot Management на средних и старших тарифах
- Чёткие SLA (97–99.99%)
- 7-дневный тестовый период
- Собственная аналитика угроз Qrator Radar / Threat Intelligence
- API для интеграции с мониторингом

**Минусы:**
- Enterprise-уровень цен — базовый от 50 000 ₽/мес
- Сложное ценообразование для небольших проектов
- Минимальная конфигурация может оказаться избыточной для маленьких сайтов

**Тарифы:** Базовый (от 7000 ₽/мес), Расширенный (от 20 000 ₽/мес), Pro (от 60 000 ₽/мес), Enterprise (от 250 000 ₽/мес), Custom (индивидуально).

**Когда выбирать:** Для проектов, где критичны SLA, качество фильтрации, минимизация ложных блокировок и экспертиза в области сетевой безопасности.

### PT Application Firewall (Positive Technologies)

**Тип:** Enterprise WAF для глубокой защиты веб-приложений и API.

**Плюсы:**
- Выявление SQLi, XSS, CSRF, RCE и других атак OWASP Top 10
- Виртуальные патчи для закрытия уязвимостей без изменения кода
- Интеграция с SIEM
- Соответствие ФСТЭК/ГОСТ/152-ФЗ
- Сертифицирован ФСТЭК России (до 2026)
- Собственная корреляция событий и ML

**Минусы:**
- Высокая стоимость владения — enterprise-сегмент
- Сложность внедрения и эксплуатации — требует опытного интегратора
- Зависимость от экосистемы одного вендора (vendor lock-in)
- Требователен к ресурсам инфраструктуры

**Тарифы:** Индивидуально. Относится к верхнему ценовому сегменту российских WAF.

**Когда выбирать:** Для крупных компаний с требованиями регуляторов (ФСТЭК, КИИ, 152-ФЗ) и необходимостью глубокой защиты веб-приложений.

### Nemesida WAF

**Тип:** WAF для защиты веб-приложений и API (on-premises).

**Плюсы:**
- Машинное обучение для обнаружения неизвестных паттернов атак
- Режим обучения для адаптации под конкретное приложение
- Адаптивные профили защиты
- API Firewall
- On-premises или облачная версия через партнёров
- Есть бесплатная версия (Nemesida WAF Free)

**Минусы:**
- Бесплатная версия сильно ограничена (нет ML, нет сканера уязвимостей)
- ML-режим требует ресурсов и увеличивает задержку
- Сложность настройки и эксплуатации
- Нет полноценного SaaS-варианта — только on-premises
- Цена зависит от набора модулей

**Тарифы:** Бесплатная версия (Nemesida WAF Free с ограничениями). Коммерческая — от 99 000 руб./год (данные 2021), с доплатой за ML, сканер уязвимостей, число экземпляров.

**Когда выбирать:** Для сценариев, где нужна тонкая защита API и приложений с ML-обнаружением неизвестных атак, и есть команда для эксплуатации.

## Как выбрать для WordPress-проекта

**Для сайта с аудиторией в РФ:**
- Cloudflare — **не рекомендуется** (блокировки с июня 2025)
- Yandex Smart Web Security + Yandex CDN — лучшая интеграция, если сайт в Yandex Cloud
- DDoS-Guard — быстрый старт с бесплатным тарифом для небольших проектов
- NGENIX — оптимален для высоконагруженных проектов с фокусом на скорость

**Для сайта с зарубежной аудиторией:**
- Cloudflare Free — по-прежнему хорошее бесплатное решение
- Qrator Labs — если нужны SLA и экспертиза

**Для интернет-магазина (WooCommerce):**
- Selectel + DDoS-Guard — если хостинг уже у Selectel
- StormWall — хорошее соотношение цена/качество для SMB

**Для проектов с требованиями ИБ (152-ФЗ, КИИ):**
- PT Application Firewall — максимальное соответствие регуляторам
- Cloud4Y — комплексная защита в сертифицированной инфраструктуре
