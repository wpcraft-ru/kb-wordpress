# Топ‑10 сервисов для защиты сайтов и CDN (включая Cloudflare)

| № | Сервис | Что закрывает (в сравнении с Cloudflare) | Ключевые особенности |
|---|---|---|---|
| 1 | **Cloudflare** | CDN, защита от DDoS (L3–L7), WAF, антибот, DNS, SSL/TLS, аналитика, Workers и др. | Глобальная сеть, ML‑анализ трафика, бесплатный тариф с базовым функционалом. Важно: с июня 2025 года у пользователей из РФ наблюдаются ограничения — соединения часто обрываются после первых 16 КБ, сайты могут плохо открываться. |
| 2 | **Yandex Smart Web Security** | Защита от DDoS (L3/L4/L7), веб‑атак (SQLi, XSS), ботов; интеграция с CDN. | ML‑модели и поведенческий анализ (Smart Protection), WAF на базе SolidWall, автоматическая SmartCaptcha, интеграция с Yandex Cloud. |
| 3 | **DDoS‑Guard** | Защита от DDoS (L3–L7), WAF, антибот, CDN, защищённый DNS. | Блокирует SYN/UDP/HTTP‑флуд, есть бесплатный тариф и пробный период, CDN‑ускорение, нет скрытых платежей за отражённые атаки. |
| 4 | **StormWall** | Защита от DDoS, фильтрация ботов, CDN. | Triple Filter, BanHammer (автораспознавание ботов), Global Session (перенаправление трафика), FlowSense (точная фильтрация). |
| 5 | **NGENIX** | Защита от DDoS (L3–L7), CDN, WAF, защищённый DNS, аналитика. | Сеть из 50+ узлов в РФ и ближнем зарубежье, пропускная способность >7 Тбит/с, мониторинг в реальном времени, в реестре российского ПО. |
| 6 | **Selectel** | Защита от DDoS (L3–L4/L7), WAF, CDN, DNS, балансировка. | Базовая L3/L4‑защита часто включена по умолчанию, можно подключать партнёрские решения (в т.ч. DDoS‑Guard) через единую панель, подробная статистика по атакам. |
| 7 | **Cloud4Y** | Защита от DDoS, WAF, комплексная защита ИТ‑инфраструктуры. | IaaS‑провайдер с фокусом на безопасность, подходит для корпоративного сегмента и работы с персональными данными, дата‑центры уровня TIER III. |
| 8 | **Qrator Labs** | Защита от DDoS (L3–L7), WAF, антибот, защищённый DNS, CDN. | Специализация на сетевой безопасности, чёткие SLA, API для интеграции с мониторингом, 7‑дневный тест, минимизация ложных блокировок. |
| 9 | **PT Application Firewall (Positive Technologies)** | Глубокая защита веб‑приложений и API (WAF). | Выявление SQLi, XSS, CSRF, RCE, виртуальные патчи, интеграция с SIEM, соответствие ФСТЭК/ГОСТ/152‑ФЗ. |
| 10 | **Nemesida WAF** | Защита веб‑приложений и API от атак (SQLi, XSS, RCE), фильтрация бот‑трафика. | Машинное обучение для неизвестных паттернов, режим обучения, адаптивные профили, API Firewall, on‑premises или облачная версия через партнёров. |

## Как быстро выбрать под задачу

* **Если вы уже в Yandex Cloud** — Yandex Smart Web Security + Yandex Cloud CDN.
* **Для быстрой защиты небольшого проекта с минимальным бюджетом** — DDoS‑Guard (есть бесплатный тариф).
* **Для корпоративного уровня с SLA** — Qrator Labs или PT Application Firewall.
* **Для высоконагруженных проектов с упором на скорость для РФ‑аудитории** — NGENIX.
* **Если нужна тонкая защита API и приложений** — PT Application Firewall или Nemesida WAF.

## Практические шаги перед подключением

1. **Запросите тестовый период** (есть у StormWall, Qrator, DDoS‑Guard и др.)
2. **Проверьте SLA** — особенно если ресурс бизнес‑критичен.
3. **Уточните условия работы с российским трафиком** — некоторые сервисы работают только по договору с юрлицом.
4. **Оцените интеграцию с текущей инфраструктурой** — DNS‑менеджмент, API, логирование.
